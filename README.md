# Epic Games Free Games Bot 🎮

A Telegram bot that notifies you every Thursday when Epic Games drops new free games — so you never miss a freebie.

## How to join

1. Open Telegram and search for **@EpicGamesFreeGamess_bot**
2. Send `/start` to subscribe

That's it! You'll get a message every Thursday with that week's free games.

## Commands

- `/start` — subscribe to weekly notifications
- `/end` — unsubscribe
- `/games` — check the current free games right now
